# Nova — социальная сеть в стиле X

Полноценная соцсеть, которая работает на вашем компьютере. Интерфейс повторяет X: тёмная тема, три колонки, лента «Для вас» / «Подписки», посты до 280 символов, ответы, репосты, цитаты, лайки, закладки, опросы, личные сообщения в реальном времени, уведомления, поиск, тренды, профили и Premium с синей галочкой.

## Запуск (Windows)

1. Установите **Node.js LTS** с https://nodejs.org (если ещё не установлен).
2. Дважды щёлкните **start.bat** — сервер запустится, браузер откроется сам.
3. Нажмите **«Войти в демо-аккаунт»** (логин `demo`, пароль `demo123`) или зарегистрируйтесь.

Остановить сервер — закройте окно консоли или нажмите `Ctrl+C`.

Без start.bat: откройте терминал в этой папке и выполните `node server.js`, затем откройте http://localhost:3000.

## Друзья в той же Wi-Fi сети

При запуске сервер печатает адрес вида `http://192.168.x.x:3000` — откройте его на телефоне или другом компьютере. Каждый может зарегистрировать свой аккаунт, и все будут видеть посты и сообщения друг друга в реальном времени. Если Windows спросит про брандмауэр — разрешите доступ для частных сетей.

## Что умеет

- **Лента**: «Для вас» (по популярности и свежести) и «Подписки» (хронологически, с репостами), плашка «опубликовали» о новых постах, бесконечная прокрутка
- **Посты**: текст с подсветкой #хэштегов, @упоминаний и ссылок, до 4 картинок (вставка из буфера и перетаскивание тоже работают), опросы, эмодзи, счётчик символов как в X
- **Действия**: ответить, репост / цитата, нравится, просмотры, закладки, поделиться, закрепить в профиле, удалить, статистика поста, кто лайкнул / репостнул
- **Ветки**: страница поста с цепочкой предков, ответами и подответами
- **Профили**: баннер, аватар, био, местоположение, сайт, дата регистрации, читатели / читаемые, «Читает вас», общие знакомые, вкладки Посты / Ответы / Медиа / Нравится, редактирование профиля
- **Обзор и поиск**: тренды по категориям, «Кого читать», поиск с подсказками, вкладки Популярное / Последнее / Люди / Медиа, `from:username`
- **Уведомления**: лайки и репосты группируются («Мария и ещё 3»), подписки, ответы, упоминания, цитаты; счётчики в меню обновляются мгновенно
- **Сообщения**: список диалогов, чат с пузырями, фото, «Прочитано», всё в реальном времени
- **Оформление**: темы «По умолчанию» / «Приглушённый» / «Без подсветки», 6 цветов акцента, 5 размеров шрифта
- **Premium**: синяя галочка и посты до 4000 символов (демо, без оплаты)
- **Мобильная версия**: нижнее меню, плавающая кнопка поста, боковое меню
- **Горячие клавиши**: `n` новый пост, `/` поиск, `j`/`k` по постам, `l` лайк, `r` ответ, `t` репост, `b` закладка, `g`+`h/e/n/m/b/p` переходы, `?` справка

## Данные

Всё хранится в папке `data`: `db.json` — база, `data/uploads` — картинки. Чтобы начать с нуля, остановите сервер и удалите папку `data` — при следующем запуске создадутся демо-пользователи и посты.

Порт можно сменить: `set PORT=8080 && node server.js`.

## Устройство

- `server.js` — сервер на чистом Node.js без зависимостей: REST API, сессии (cookie), хеширование паролей (scrypt), realtime через Server-Sent Events
- `seed.js` — демо-данные (пользователи, посты, ответы, опросы, сообщения, сгенерированные картинки)
- `public/` — клиент: одностраничное приложение на JavaScript-модулях без фреймворков
  - `js/app.js` — каркас, роутер, боковая панель, realtime
  - `js/post.js` — посты, лента, поле публикации
  - `js/ui.js` — модальные окна, меню, тосты, карточки пользователей
  - `js/pages/*` — страницы
  - `css/style.css` — все стили и темы

Название и логотип меняются в `public/js/util.js` (`APP_NAME`) и `public/js/icons.js` (`logo`).
